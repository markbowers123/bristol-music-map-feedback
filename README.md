# Bristol Music Map feedback copy

This is a public, read-only feedback copy of the Bristol Music Map. It contains only the map page and its public browser files. It does not contain the research register, source notes, local databases or suggestion queue.

The working version remains at [Bristol Music Map](https://bristol-music-map.markbowers1125.chatgpt.site/). Changes made there do not update this feedback copy automatically. The GitHub Pages copy is for sharing with a small group of reviewers.

GitHub Pages publishes the files in `public/` whenever they are pushed to `main`. It needs a public repository on GitHub Free. The map itself can be viewed by anyone who has its Pages link.
