# Bristol Music Map feedback copy

This is a public, read-only feedback copy of the Bristol Music Map. It contains the map page and its public browser files. It does not contain the research register, source notes, local databases or suggestion queue.

The working version remains at [Bristol Music Map](https://bristol-music-map.markbowers1125.chatgpt.site/). Changes made there do not update this feedback copy automatically. This copy is for sharing with a small group of reviewers. Anyone who has the Pages link can view it.

GitHub Pages publishes the `docs/` folder from `main`. To share the map, use the Pages link shown in the repository's Settings under Pages.
